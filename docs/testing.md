# Testing Plan

## Backend starter
- [ ] Start the Python service in a virtual environment.
- [ ] Confirm `GET /health` returns a healthy status.
- [ ] Confirm the service binds to localhost by default.

## ESP32 hardware (when delivered)
- [ ] Identify the exact module and USB-to-serial chip.
- [ ] Confirm the board appears as a serial device.
- [ ] Upload a minimal serial-output sketch.
- [ ] Scan for I²C devices.
- [ ] Confirm OLED output.
- [ ] Connect to Wi-Fi and record RSSI.
- [ ] Compare latency readings with a PC-side reference.

Record test date, hardware revision, software version, expected result, actual result, and notes.
